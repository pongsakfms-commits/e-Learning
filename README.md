# e-Learning Admin Panel

ระบบจัดการข้อมูลผู้เรียนสำหรับผู้ดูแล (Admin) โดยรองรับการจัดการข้อมูลพื้นฐาน ค้นหา กรอง รีเซ็ตรหัสผ่าน นำเข้าข้อมูลผ่าน CSV และส่งออกข้อมูลเบื้องต้นเป็นไฟล์ CSV

## คุณสมบัติหลัก

- 📋 แสดงรายการผู้เรียนพร้อมรายละเอียดสำคัญ (ชื่อ อีเมล สถานะการสอบ วันที่สร้าง/อัปเดต)
- 🔍 ค้นหาและกรองข้อมูลตามชื่อ อีเมล และสถานะการสอบได้
- ➕ สร้าง/แก้ไข/ลบผู้เรียน (CRUD) พร้อมการตรวจสอบความถูกต้องของข้อมูล
- 📤 นำเข้าข้อมูลผู้เรียนจากไฟล์ CSV แบบ batch พร้อมรายงานผลสำเร็จและข้อผิดพลาด
- 🔐 รีเซ็ตรหัสผ่านผู้เรียนพร้อมบันทึกเวลารีเซ็ตล่าสุด
- ✅ มีการตรวจสอบสิทธิ์ผ่าน `adminToken` และตรวจสอบข้อมูลด้วย policy/validation บนฝั่งเซิร์ฟเวอร์
- 📄 รองรับการแบ่งหน้า (pagination) และส่งออกข้อมูลผู้เรียนเป็นไฟล์ CSV เบื้องต้น (UTF-8 with BOM)

## การติดตั้งและใช้งาน

### ความต้องการเบื้องต้น

- Node.js เวอร์ชัน 18 ขึ้นไป
- npm

### ขั้นตอนการเริ่มใช้งาน

```bash
npm install
npm start
```

เมื่อเซิร์ฟเวอร์เริ่มทำงานแล้ว สามารถเข้าถึงระบบได้ที่:

```
http://localhost:3000/
```

หน้าหลักจะพาไปยังหน้าจัดการผู้เรียนพร้อมแนบ `adminToken` ให้โดยอัตโนมัติ (ค่าเริ่มต้นคือ `admin123`).

หากต้องการกำหนด token เอง สามารถตั้งค่า environment variable ก่อนสตาร์ตเซิร์ฟเวอร์:

```bash
export ADMIN_TOKEN=my-secret-token
npm start
```

จากนั้นเข้าถึงระบบด้วย URL ที่มี `adminToken` ตรงกับค่าที่ตั้ง:

```
http://localhost:3000/admin/students?adminToken=my-secret-token
```

## โครงสร้างข้อมูล

ระบบเก็บข้อมูลผู้เรียนในไฟล์ JSON (`src/data/students.json`) เพื่อความสะดวกในการเดโม โดยแต่ละเรคคอร์ดประกอบด้วยฟิลด์:

- `id` (UUID)
- `firstName`, `lastName`
- `email`
- `examStatus` (`not_started`, `in_progress`, `passed`, `failed`)
- `passwordHash`
- `createdAt`, `updatedAt`
- `lastPasswordResetAt`

> **หมายเหตุ:** รหัสผ่านถูกเก็บในรูปแบบแฮช SHA-256 เสมอ และการรีเซ็ตรหัสผ่านจะแสดงค่าใหม่ให้ผู้ดูแลเห็นเพียงครั้งเดียวผ่านข้อความแจ้งเตือน

## การนำเข้าข้อมูลผู้เรียนผ่าน CSV

ระบบรองรับการนำเข้าข้อมูลผู้เรียนแบบ batch ผ่านไฟล์ CSV โดยมีรายละเอียดดังนี้:

### รูปแบบไฟล์ CSV

ไฟล์ CSV ต้องมีหัวตารางและคอลัมน์ดังต่อไปนี้:

```csv
firstName,lastName,email,password,examStatus
สมชาย,ใจดี,somchai@example.com,pass1234,not_started
สมหญิง,รักดี,somying@example.com,pass5678,in_progress
```

**คอลัมน์ที่ต้องการ:**
- `firstName` - ชื่อผู้เรียน (ไม่ว่าง)
- `lastName` - นามสกุลผู้เรียน (ไม่ว่าง)
- `email` - อีเมลผู้เรียน (ต้องเป็นรูปแบบอีเมลที่ถูกต้องและไม่ซ้ำกับที่มีอยู่)
- `password` - รหัสผ่าน (ความยาว 6-50 ตัวอักษร)
- `examStatus` - สถานะการสอบ (ต้องเป็นหนึ่งใน: `not_started`, `in_progress`, `passed`, `failed`)

**ข้อกำหนด:**
- ไฟล์ต้องเป็นนามสกุล `.csv` เท่านั้น
- ขนาดไฟล์ไม่เกิน 5MB
- จำนวนแถวไม่เกิน 1,000 แถว (ไม่รวมแถวหัวตาราง)
- การเข้ารหัสควรเป็น UTF-8

### วิธีการนำเข้า

1. คลิกปุ่ม "นำเข้า CSV" ในหน้าจัดการผู้เรียน
2. เลือกไฟล์ CSV ที่ต้องการนำเข้า
3. ระบบจะตรวจสอบและประมวลผลแบบ batch
4. หลังจากเสร็จสิ้น ระบบจะแสดงสรุปผล:
   - จำนวนข้อมูลที่นำเข้าสำเร็จ
   - จำนวนข้อมูลที่ล้มเหลว
   - รายการข้อผิดพลาดแต่ละแถว (ถ้ามี)

### การจัดการข้อผิดพลาด

หากมีข้อมูลบางแถวไม่ผ่านการตรวจสอบ:
- ระบบจะข้ามแถวที่มีปัญหาและดำเนินการนำเข้าข้อมูลแถวอื่นที่ถูกต้องต่อไป
- รายงานข้อผิดพลาดจะระบุหมายเลขแถวและข้อความอธิบายปัญหาให้ชัดเจน
- ผู้ดูแลสามารถแก้ไขข้อมูลและนำเข้าใหม่ได้

## หมายเหตุเพิ่มเติม

- แอปพลิเคชันนี้เป็นตัวอย่างสำหรับการบริหารจัดการผู้เรียนบนระบบ e-Learning สามารถต่อยอดเชื่อมต่อฐานข้อมูลจริงได้ในอนาคต
- การส่งออก/นำเข้า CSV เป็น placeholder สำหรับการใช้งานพื้นฐาน สามารถปรับปรุงเพิ่มเติมเพื่อนำไปใช้กับข้อมูลปริมาณมากได้
- หากแก้ไขไฟล์ `students.json` โดยตรง ควรปิดเซิร์ฟเวอร์ก่อนเพื่อหลีกเลี่ยงปัญหาการเขียนทับข้อมูล
