# e-Learning Python Course

ระบบหน้าเว็บสำหรับนำเสนอคอร์ส Python ที่ออกแบบมาให้ผู้เรียนสามารถดูภาพรวมบทเรียน เข้าเรียนทีละหัวข้อ พร้อมติดตามความคืบหน้าของตนเองได้ รวมทั้งมีหน้าสำหรับโปรเจกต์สุดท้ายพร้อมคำแนะนำและแบบฟอร์มส่งงาน (placeholder)

## คุณสมบัติหลัก

- **หน้า Landing/Overview**
  - แสดงชื่อคอร์ส คำอธิบาย และสถิติความคืบหน้าโดยรวม
  - ลิสต์บทเรียนตามลำดับที่กำหนด และแสดงสถานะเรียนแล้ว/ยังไม่เรียน
- **หน้า Lesson Detail**
  - แสดงวัตถุประสงค์ เนื้อหา ตัวอย่างโค้ด และสื่อประกอบของแต่ละบท
  - มีปุ่มทำเครื่องหมายว่าเรียนจบ เพื่ออัปเดตความคืบหน้าใน Local Storage
  - แสดงสถานะความคืบหน้า (จำนวนบทที่เรียนแล้ว/ทั้งหมด) พร้อมปุ่มไปยังบทก่อนหน้า/ถัดไป
- **การบันทึกความคืบหน้า**
  - บันทึกสถานะบทเรียนที่เรียนจบไว้ใน `localStorage` บนเบราว์เซอร์ของผู้ใช้
  - แสดงเปอร์เซ็นต์ความคืบหน้าทั้งในหน้า Landing และหน้า Lesson Detail
- **หน้า Final Project**
  - รวบรวมวัตถุประสงค์ ข้อกำหนด สิ่งที่ต้องส่ง และแนวคิดโปรเจกต์ให้เลือก
  - แสดงความคืบหน้าเพื่อบอกว่าพร้อมทำโปรเจกต์หรือไม่
  - มีแบบฟอร์มส่งโปรเจกต์ (placeholder) ที่ยังไม่บันทึกข้อมูลจริง แต่แสดงข้อความตอบกลับทันที

## โครงสร้างไฟล์สำคัญ

```
project/
├── index.html               # หน้า Landing/Overview
├── lesson.html              # หน้าแสดงรายละเอียดบทเรียน
├── final-project.html       # หน้าโปรเจกต์สุดท้าย + ฟอร์มส่งงาน
├── assets/
│   ├── css/
│   │   └── styles.css       # สไตล์หลักของเว็บไซต์
│   └── js/
│       ├── lessons-data.js  # ข้อมูลคอร์สและบทเรียน
│       ├── app.js           # ฟังก์ชันหลัก + การจัดการความคืบหน้า
│       ├── lesson-detail.js # สคริปต์เฉพาะหน้า lesson.html
│       └── final-project.js # สคริปต์เฉพาะหน้า final-project.html
└── README.md
```

## วิธีใช้งาน

1. เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์สมัยใหม่ (Chrome, Firefox, Edge ฯลฯ)
   - สามารถดับเบิลคลิกไฟล์เพื่อเปิดได้ทันที หรือ
   - รันเว็บเซิร์ฟเวอร์แบบง่าย เช่น `python3 -m http.server` แล้วเข้าผ่าน `http://localhost:8000`
2. คลิกดูรายละเอียดบทเรียนในหน้า Landing เพื่อไปยัง `lesson.html`
3. ใช้ปุ่ม **"✓ ทำเครื่องหมายว่าเรียนแล้ว"** เพื่อบันทึกความคืบหน้าของบทนั้น
4. เมื่อเรียนครบทุกบท ให้ไปที่หน้า **โปรเจกต์สุดท้าย** เพื่อดูคำแนะนำและทดลองส่งงานผ่านแบบฟอร์ม (placeholder)

> ℹ️ การบันทึกความคืบหน้าใช้ `localStorage` ของเบราว์เซอร์ หากล้างข้อมูลเว็บไซต์หรือเปิดด้วยเบราว์เซอร์/อุปกรณ์อื่น ข้อมูลความคืบหน้าจะเริ่มใหม่

## การปรับแต่งข้อมูลคอร์ส

- แก้ไขรายละเอียดบทเรียนหรือโปรเจกต์สุดท้ายได้ที่ไฟล์ `assets/js/lessons-data.js`
- สามารถเพิ่ม/ลบ/จัดลำดับบทเรียนได้จากอาร์เรย์ `lessons` โดยปรับ `order` ให้เรียงตามที่ต้องการ

## ข้อกำหนดเบราว์เซอร์

- ต้องรองรับ ES6 modules และ `localStorage` (เบราว์เซอร์หลักที่อัปเดตในช่วงไม่กี่ปีที่ผ่านมาใช้ได้ทั้งหมด)
- หากมีการบล็อก `localStorage` หรือใช้โหมดไม่ระบุตัวตน ความคืบหน้าจะไม่ถูกบันทึก
