# e-Learning Platform by Pom

A modern, responsive e-learning platform with separate interfaces for learners and administrators.

## Features

### Responsive Design
- Mobile-first approach with Bootstrap 5
- Fully responsive layouts for all screen sizes
- Collapsible sidebar navigation on mobile devices
- Touch-friendly interface

### Learner Interface
- Personal dashboard with course progress
- Course catalog and enrollment
- Assignment tracking and submissions
- Certificate management
- Progress analytics

### Admin Interface
- Comprehensive dashboard with statistics
- Course management system
- User and instructor management
- Activity monitoring and reports
- System settings and configuration

## Technology Stack

- **Frontend Framework**: Bootstrap 5.3.2
- **Icons**: Bootstrap Icons 1.11.1
- **CSS**: Custom responsive styling with CSS variables
- **JavaScript**: Vanilla JS for interactions
- **Design**: Modern card-based UI with gradient accents

## Color Scheme

- Primary: #4A90E2 (Blue)
- Secondary: #50C878 (Green)
- Accent: #FF6B6B (Red)
- Dark: #2C3E50
- Light: #F8F9FA

## Getting Started

1. Clone the repository
2. Open `learner-dashboard.html` for the learner interface
3. Open `admin-dashboard.html` for the admin interface
4. Open `components-demo.html` to view all available UI components
